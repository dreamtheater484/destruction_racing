## Our own work
- **Car models:** generated by this project. `tools/carsmith` (Python, signed-distance bodies) does the modelling; Blender only decimates and exports.
- **Liveries and race numbers:** this project's work. The digits are our own block face, drawn in `tools/carsmith/digits.py`, so no font licence is involved.
- **Fictional brands** (Kitsune, Aldridge, Nordvik): this project's own work.
- **Engine sounds:** synthesized by this project (`tools/enginesynth`); there are no recordings.
- **The Bowl** (arena geometry, stands, scoreboard): generated by this project (`src/Tools/BowlLookBuilder.gd`).
